Files starting with an underscore are ignored by the build. Copy this file to
`content/notes/your-note-slug.md`, edit it, and run `node build.mjs`. The first
real note makes Notes appear in the navigation and on the homepage.

## Supported formatting

Paragraphs, `## headings`, **bold**, *italic*, `inline code`,
[links](https://willbuilds.ai), lists and fenced code blocks.
